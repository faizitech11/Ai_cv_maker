 AI CV Maker

AI CV Maker is a web-based application that helps users create professional CVs easily.

Users can either create a CV from scratch or upload an existing CV. The system extracts information from uploaded CVs, converts it into structured CV data, and allows users to review and edit the information before generating the final CV.

 Features

- User registration and login
- Secure authentication and session management
- Create and manage multiple CVs
- Edit and delete CVs
- Personal information management
- Education and experience management
- Skills, projects and certifications
- Languages and other CV information
- Upload existing CV files
- PDF and DOCX text extraction
- Structured CV data processing
- AI-assisted CV content improvement
- Professional summary generation
- AI-assisted experience and project descriptions

 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- MySQL
- Prisma ORM
- NextAuth
- Hugging Face API
- PDF/DOCX parsing
